Plugin Location

  • Project Directory: /home/trkr/qgis/parselsorguv2
  • QGIS Plugin Directory: /home/trkr/.local/share/QGIS/QGIS3/profiles/default/python/plugins

What's Next?

  1. Navigate to your plugin directory.
  2. Compile the resources file using pyrcc5:
    make (if you have a Makefile) or use pb_tool
  3. Test the plugin:
    make test or use your IDE's test runner
  4. Copy the entire plugin directory to the QGIS plugin directory above.
  5. Open QGIS and enable the plugin from the Plugin Manager.
  6. Edit the plugin logic in ParselSorguV2.py to suit your requirements.
  7. Replace the default icon by modifying icon.png.
  8. Modify the user interface using ParselSorguV2_dockwidget_base.ui in Qt Designer.

Notes

  • The Makefile can be used to automate compilation and deployment. You may need to edit it to include any new Python files, dialogs, or translations.
  • Alternatively, use pb_tool for plugin building. Update the pb_tool.cfg file as you add new files.
    Install it using: pip install pb_tool
